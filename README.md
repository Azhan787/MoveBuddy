# 🚚 MoveBuddy — Transport & Logistics Website

MoveBuddy is a modern, responsive transport and logistics website designed to provide users with a simple and professional way to explore transportation services, request quotes, and get in touch with a transport service provider.

🔗 **Live Demo:** https://azhan787.github.io/MoveBuddy/

---

## 📌 About The Project

MoveBuddy is a fully responsive business website created for a transport and logistics service.

The website focuses on providing a clean, modern, and user-friendly experience where customers can:

* Explore available transport services
* Learn more about the company
* Request a transportation quote
* View frequently asked questions
* Explore different vehicle and transport options
* Contact the business
* Browse the website easily on desktop, tablet, and mobile devices

## 🚀 Getting Started

Since this is a static HTML, CSS, and JavaScript project, no package installation is required.

### 1. Clone the repository

```bash
git clone https://github.com/Azhan787/MoveBuddy.git
```

### 2. Open the project

```bash
cd MoveBuddy
```

### 3. Run the website

Simply open:

```text
index.html
```

in your browser.

For the best development experience, you can also use **Visual Studio Code + Live Server**.
